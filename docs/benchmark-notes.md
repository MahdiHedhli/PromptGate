# Benchmark Notes

AI4Privacy PII-Masking-300k is referenced as an external benchmark option only. It is not included in this repository. Review and comply with the dataset license before using it, especially for commercial, redistributed, derivative, or training use.

GitHub Issues Secrets Benchmark is a useful prompt-like secret detection benchmark reference. It is not included in this repository.

PromptGate does not train on external datasets during the MVP. Evaluation should use local synthetic prompts, licensed internal fixtures, or external datasets only after license review.
